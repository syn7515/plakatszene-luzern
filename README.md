# Plakatszene Luzern — interactive

[Plakatszene Luzern](https://100-beste-plakate.de/plakate/plakatszene-luzern/) 포스터(Isabelle Mauchle, Felix Pfäffli, Erich Brechbühl, 2025)를
Three.js로 다시 만드는 실험. 말려 있는 종이가 펴지고 다시 말리는 인터랙션이 핵심.

## 원칙

- **납작한 3D:** 조명, 그늘, 그림자 없음. 직교 카메라, 별색 5개 + 종이 흰색
- **색은 보이는 면에 붙음:** 종이 위 위치가 아니라, 고정된 끝부터 센 "보이는 면"마다 한 색. 새 면은 카메라에서 볼 때 종이가 시선과 나란해져 앞뒷면이 바뀌는 곳에서 시작하므로, 얼마나 말려 있든 어떻게 놓여 있든 이어져 보이는 면은 항상 한 색
- **망점은 면의 색:** 그림자가 아니라 잉크 5개로 색을 더 만드는 방법. 격자는 포스터에 고정돼서 휘어진 면에서도 균일
- **종이 모양 = 구간 목록:** 구간마다 "이 길이 동안 몇 도 휘는지"(+ 앞면 쪽, − 뒷면 쪽). 직선, 접힘, 머리핀, 지그재그, 간격이 제각각인 나선을 모두 표현. 휘는 정도는 이웃 구간 사이에서 서서히 바뀌어 종이처럼 흐름 (각 구간의 총 각도는 그대로)
- **윗선·아랫선 따로:** 구간마다 아랫선이 휘는 각도를 따로 줄 수 있음("아랫선 따로 휘기"). 두 선 사이는 곧은 선으로 이어져서, 그 구간만 비스듬히 서거나 벌어지거나 오므라듦. 한 종이 안에서도 일부 면만 기울어질 수 있음
- **바닥이 있는 공간:** 포스터들은 바닥 위에 세로로 세워져 있음
  - 바닥에 선 종이: 아랫선이 바닥에 닿아 있어서 앞뒤·옆으로 눕힐 수 없고, 깊이는 화면에 보이는 아랫선 위치로 정해짐
  - 떠 있는 종이: 아직 바닥에 닿기 전이라 자유롭게 기울어짐. 그래서 윗선과 아랫선의 곡선이 다르게 보임 (crescent-lavender)
- **종이는 서로를 뚫지 않음:** 맞물리거나 감싸는 건 되지만 관통은 안 됨. 바닥 아래로도 내려갈 수 없음
- **모든 종이는 포스터 비율:** F4(가로 1.43, 세로 0.70)를 크기만 달리해서 씀(A0~A3처럼). 아랫부분이 다른 종이에 가려지는 건 상관없음. 그래서 띠처럼 보이는 종이도 실은 키 큰 포스터의 윗부분
- **종이가 종이를 따라감:** 겹쳐 선 종이들은 한 장(선두)만 자기 구간 목록을 갖고, 나머지는 그 종이의 앞면 쪽/뒷면 쪽을 "따라감". 고정 간격이 아니라 종이 성질로 정해짐: 빳빳함(0 = 상대 곡선에 딱 붙음, 1 = 자기 기억대로), 말림 기억(°/cm), 장력(간격으로 되돌아오는 세기), 간격(cm). 상대를 뚫으려 하면 밀려나서 미끄러짐. 따라가는 종이는 위치·회전이 상대에서 유도되고, 따라가는 구간 앞뒤에 자기만의 말림을 붙일 수 있음
- **물리 시뮬레이션 없음:** 종이마다 `curl` 값(0 평평 ~ 1 원래 모양)을 두고 스프링으로 움직임. 펴질 때 종이 길이는 유지
- **당기면 롤만 풀린다:** 종이마다 "풀리는 구간"(`pull.from` → `pull.to`, cm)을 두면 당길 때 그 구간만 `from` 쪽부터 펴지고 몸통은 그대로 선다. 롤이 끝에 있으면 롤이 몸통에서 멀어지며 풀리고, 고정된 끝에 있으면 제자리에서 풀린다. 드래그는 `from` 지점의 종이 결 방향으로 읽는다. 구간이 없으면 고정된 끝부터 전부 펴진다(따라가는 종이는 따라가는 구간 바깥쪽부터)
- **윗선은 말림을 조금 더 붙든다:** 당겨 펼 때 아랫선이 먼저 펴지고 윗선은 `topLag`(기본 0.3)만큼 말림을 남겨서, 실제 포스터처럼 윗부분이 롤 쪽으로 살짝 말려 올라간 듯 보인다
- **열릴 때 종이가 자란다:** 페이지를 열면 종이마다 고정된 끝에서 자기 경로를 따라 길이가 0 → 100%로 자란다. 뒤쪽 종이부터 60ms 간격으로 시작하고 따라가는 종이는 선두보다 늦게, 한 장당 1.4초. 곡선은 cubic-bezier(0.55, 0, 0.15, 1): 롤에서 풀려 나오듯 천천히 시작해 빠르게 풀리고 길게 가라앉음. 길이는 100%를 넘을 수 없으니 도착 순간 말림을 ease로 살짝 풀었다가(0.25초) 천천히 되돌림(1.2초). 스프링이 아니라 진동 없이 한 번만. 도착 순간 가장 깊은 지점에서 관통을 한 번 검사해, 생기면 반대로(살짝 더 말기), 그래도 생기면 생략. 따르는 종이가 있는 선두는 이 동작을 하지 않고(따르는 종이가 같이 흔들리므로), 따르는 종이는 선두가 자란 만큼만 뒤따라 자람. 편집기(?edit)는 생략 (`poster-scene.ts`의 GROW, STAGGER, SETTLE, DIP, RECOVER, EASE)
- **숨쉬기:** 안착이 끝나도 종이는 완전히 멈추지 않는다. 모든 굽힘이 같은 비율로 살짝 느슨해졌다 돌아오기를 반복한다(n-wrap처럼 모서리 숙임이 있는 종이는 대신 코너를 전체의 50%까지 숙임). 깊이는 굽힘 5%가 기본이지만 그만큼에서 종이의 어느 점이든 3cm보다 멀리 가면 3cm가 되도록 줄인다(긴 종이가 부채처럼 흔들리지 않게). 열리기 전에 모든 종이를 한꺼번에 가장 깊이 숨 쉰 상태로 두고 관통 검사를 해서, 닿는 쌍은 더 멀리 움직이는 쪽을 반대 방향(절반 깊이로 더 말기)으로 바꾸고, 그래도 닿으면 그 종이는 숨쉬기를 하지 않는다. 따르는 종이는 선두와 같이 움직이므로 선두가 책임진다. 주기는 종이 id에서 정해져 5~10초, 거기에 황금비(1.618배)만큼 느린 두 번째 파동을 40% 섞어 같은 모양이 되풀이되지 않게 한다. 두 파동 모두 0에서 시작하므로 안착에서 이어질 때 끊김이 없다. 따르는 종이가 있는 선두는 따르는 종이가 모두 도착한 뒤 시작하고, 당기는 동안은 그 종이만 숨을 멈춘다. 편집기에서는 없음 (`poster-scene.ts`의 BREATH, BREATH_REACH, BREATH_TIGHTER, BREATH_DROOP, BREATH_PERIOD, BREATH_SECOND)
- **모서리 숙임:** 종이에 `droop: { turn, reach }`를 주면 열림이 끝나는 순간 말림 풀기 대신, 고정된 끝의 마지막 `reach` cm가 경첩을 축으로 `turn`°(+ 앞면 쪽)만큼 숙여졌다가 1.2초에 걸쳐 돌아온다. 윗선은 각도 전부, 아랫선은 40%라 위 모서리가 더 숙여진다. n-wrap에 −35°/14cm
- **호버 포커스:** 열림과 안착이 모두 끝난 뒤 포인터를 종이 위에 올리면 그 종이만 색을 지키고 나머지는 전부 채도 0이 되고, 남은 밝기는 감마 공간에서 30% 흰색 쪽으로 올라가 뒤로 물러난다(`paper.frag.glsl`의 LIFT). 벗어나면 전부 돌아온다. 시간상수 0.12초의 지수 ease. 포스터를 골라 클릭해 보는 인터페이스의 첫 단계이고 클릭 이후는 아직 없음. 당기는 동안은 잡은 종이가 포커스. 편집기에서는 없음 (`poster-scene.ts`의 FOCUS, `paper.frag.glsl`의 uSaturation, `pull.ts`의 hover 콜백)
- **당기다 닿으면 멈춘다:** 당기는 종이는 매 프레임 다른 종이·바닥과 관통 검사를 해서, 닿으면 직전 값으로 돌아가고 스프링이 거기에 걸린다. 밀치기는 따라가는 종이들만(선두를 당기면 따르는 종이가 접촉으로 밀려남). 이미 겹친 채 시작한 종이는 막지 않는다

## 실행

```bash
npm install
npm run dev
```

편집기는 개발 서버에서 `http://localhost:5173/?edit` 로 열어요. 배포용 빌드에는 들어가지 않아요.

## 편집기

- 원본 포스터가 캔버스 위에 반투명하게 겹쳐 보임 (100 Beste Plakate 사이트에서 직접 불러옴, 프로젝트에 저장하지 않음)
- 종이 클릭 = 선택, 드래그 = 이동, 방향키 = 0.5cm 이동 (Shift = 5cm)
- `R` 원본 보이기/숨기기, `⌘D` 복제
- 모드를 "당기기"로 바꾸면 실제 페이지처럼 종이를 당겨볼 수 있음
- 바꿀 때마다 `src/composition.json` 에 자동 저장 (되돌리기 없음)
- 관통 검사: 패널 맨 위 "관통"에 몇 쌍인지, 화면에 빨간 점으로 위치 표시. 높이별 단면을 비교해서 기울어진 종이도 검사하고, 바닥 아래로 내려간 종이도 찾음
- "바닥에 서 있음"을 켜면 높이와 앞뒤·옆 기울기가 잠기고, 드래그와 위아래 방향키는 앞뒤(깊이)로 움직임
- "아랫선 따로 휘기"를 켜면 구간마다 아랫선 각도 슬라이더가 나타남
- "당기기" 폴더: 풀리는 구간 시작·끝(cm)과 윗선 말림 유지(0~1)
- "따라가기"를 켜면 따라갈 종이, 면, 시작 지점, 간격, 빳빳함, 말림 기억, 장력, 반대 방향이 나오고, 구간 목록에서 어느 구간이 따라가는지 고름. 따라가는 종이는 끌 수 없고, 좌우 방향키가 시작 지점을 움직임
- 짧은 구간은 이웃과 섞여 명목 각도보다 훨씬 덜 꺾임. 면을 바꾸려고 주름을 넣을 때는 2cm에 ±200° 정도는 줘야 모서리를 넘음

## 원본에서 읽어낸 것

- 종이는 세로로 선 띠이고, 약 25° 위에서 내려다본 시점. 말린 윗면이 타원으로 보임
- 나선은 지름 약 40cm, 2바퀴 이상. 바퀴마다 색이 달라서 겹친 바퀴가 구분됨
- 색이 바뀌는 곳은 앞뒷면이 바뀌는 접힌 가장자리뿐. 하나로 이어진 면 안에서는 색이 바뀌지 않음
- 그림자와 그늘은 표현하지 않음. 모든 면이 평평한 색
- 망점은 면을 채우는 방법 중 하나. 두 가지가 쓰임
  - 연보라: 흰 종이 위 보라 점 약 25% (큰 종이의 안쪽 면에 많이 쓰임)
  - 짙은 초록: 초록 위에 보라 점 약 80%를 겹쳐 찍음 (초록 × 보라 ≈ 스캔의 `#021927`, 초록이 작은 구멍으로 보임)
- 망점 격자는 45°, 간격 약 0.38cm

## 구조

- `src/composition.json` — 포스터 전체 데이터: 시점, 바닥 높이, 망점, 스프링, 종이 목록. 편집기가 저장함
- `src/composition.ts` — 위 데이터의 형식과 저장용 직렬화
- `src/poster.ts` — 원본 포스터 정보: F4 크기, 잉크, 면 팔레트(잉크 5 + 종이 + 망점 2)
- `src/stage.ts` — 렌더러, 직교 카메라(내려다보는 각도), 리사이즈. 캔버스 = 포스터 한 장
- `src/poster-scene.ts` — composition으로 종이들을 만들고 매 프레임 갱신. 따라가는 종이는 선두 종이 다음에 빌드
- `src/sheet.ts` — 종이 한 장: 위치, 회전(바닥에 선 종이는 바닥에 고정), 형태, 면 색, 스프링
- `src/strip-geometry.ts` — 종이 형태(구간 목록). 윗선과 아랫선을 각각 곡률 적분으로 그려서 길이를 유지하며 말리고 펴짐. 따라가는 구간은 상대 종이의 선을 따라 한 걸음씩 추적(접촉·빳빳함·장력). 보이는 면 세기
- `src/materials.ts`, `src/shaders/` — 종이 재질, 망점, 면마다 색
- `src/spring.ts`, `src/pull.ts` — 스프링(위아래 멈춤값)과 당기기(종이 결 방향 드래그, 풀리는 구간 길이 기준)
- `src/collisions.ts` — 종이끼리(또는 스스로) 뚫는 곳, 바닥 아래로 내려간 종이 찾기. 당기는 종이 한 장만 매 프레임 검사하는 `collisionsOf`
- `src/editor.ts` — `?edit` 편집기 (개발 전용)
- `vite.config.ts` — 편집기가 composition.json 을 저장하는 개발 서버 경로
- `src/main.ts` — 시작점
